## 任务二：`src-tauri/src` 后端代码解析

这是一个 **Tauri + Rust** 桌面笔记应用后端（类似 Obsidian），负责文件系统操作、笔记索引、全文搜索和链接图谱。整体架构如下：

### 架构总览

```
src-tauri/src/
├── main.rs          # 入口，调用 lib::run()
├── lib.rs           # 应用启动：注册插件、初始化状态、注册命令
├── state.rs         # 全局应用状态（Tauri State 容器）
├── commands.rs      # Tauri 命令层（前后端桥接的 #[tauri::command]）
├── vault.rs         # 仓库注册表管理（增删改查 + 持久化）
├── parser.rs        # Markdown 解析器（提取链接、标签、标题）
├── watcher.rs       # 文件系统监听器（实时感知文件变化）
├── error.rs         # 统一错误类型定义
└── index/
    ├── mod.rs       # 模块声明
    ├── graph.rs     # 链接索引（双向链接、图谱导出）
    └── search.rs    # 全文搜索引擎（基于 Tantivy）
```

---

### 各文件详解

#### [main.rs](file:///Users/zmh/Documents/code/roc/roc/src-tauri/src/main.rs) — 程序入口
极简入口，仅调用 `roc_lib::run()`。`#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]` 在 Release 模式下隐藏 Windows 控制台窗口。

#### [lib.rs](file:///Users/zmh/Documents/code/roc/roc/src-tauri/src/lib.rs) — 应用启动核心
- **注册插件**：`tauri_plugin_opener`（打开外部链接）、`tauri_plugin_fs`（文件系统访问）、`tauri_plugin_dialog`（对话框）、`tauri_plugin_os`（系统信息）
- **初始化状态**（`setup` 回调）：
  - 数据目录设为 `./.roc-data`
  - 从 `vaults.json` 加载仓库注册表，构建 `AppState` 并注入 Tauri 的状态管理
- **注册命令**：通过 `generate_handler!` 注册了 21 个前后端通信命令（打开/切换/关闭仓库、列笔记、搜索、重命名、删除、获取图谱等）

#### [state.rs](file:///Users/zmh/Documents/code/roc/roc/src-tauri/src/state.rs) — 全局状态容器
`AppState` 是整个后端的共享状态，通过 Tauri 的 `State<>` 注入到各命令中：

| 字段 | 类型 | 作用 |
|------|------|------|
| `current_vault` | `RwLock<Option<VaultInfo>>` | 当前打开的仓库 |
| `vault_registry` | `RwLock<VaultRegistry>` | 所有已注册仓库 |
| `link_index` | `LinkIndex` | 笔记间的双向链接索引 |
| `search_index` | `SearchIndex` | Tantivy 全文搜索索引 |
| `watcher` | `Mutex<Option<Debouncer>>` | 文件监听器 |

使用 `RwLock`（读写锁）和 `Mutex`（互斥锁）保证线程安全，`parking_lot` 提供高性能锁实现。

#### [vault.rs](file:///Users/zmh/Documents/code/roc/roc/src-tauri/src/vault.rs) — 仓库注册表
- `VaultInfo`：仓库信息（id、name、path、last_opened）
- `VaultRegistry`：用 `HashMap<String, VaultInfo>` 管理多个仓库，支持序列化到 `vaults.json`
- `generate_vault_id()`：用 **SHA-256** 对仓库路径取哈希作为唯一 ID，避免路径冲突

#### [commands.rs](file:///Users/zmh/Documents/code/roc/roc/src-tauri/src/commands.rs) — 命令层（前后端桥接）
所有 `#[tauri::command]` 函数，前端通过 `invoke('命令名', 参数)` 调用。核心命令：

| 命令 | 功能 |
|------|------|
| `open_vault` | 打开仓库：注册到注册表 → 授权文件系统访问 → 启动文件监听 → 构建链接索引 + 搜索索引 → 发出 `vault-opened` 事件 |
| `add_vault_by_path` | 仅注册仓库（不打开） |
| `switch_vault` | 切换到指定仓库（内部调用 `open_vault`） |
| `close_vault` | 关闭当前仓库：清空状态 + 停止监听 + 关闭搜索索引 |
| `list_all_notes` | 列出所有笔记元数据 |
| `get_backlinks` | 获取某笔记的反向链接 |
| `rename_note` | 重命名笔记 + **自动更新所有引用此笔记的 wikilink** + 更新索引 |
| `delete_note` | 删除笔记 + 清理索引 |
| `search` | 全文/标签/链接搜索 |
| `get_graph` | 导出图谱数据（节点 + 边） |
| `create_note` | 创建新笔记（以时间戳命名） |

#### [parser.rs](file:///Users/zmh/Documents/code/roc/roc/src-tauri/src/parser.rs) — Markdown 解析器
用正则表达式解析 Obsidian 风格的 Markdown 语法：

| 函数 | 提取内容 | 正则 |
|------|----------|------|
| `extract_links` | `[[wikilink]]` 双向链接 | `\[\[([^\]\|#]+)...\]\]` |
| `extract_tags` | `#tag` 标签 | `#(\w[\w\-_]*)` |
| `extract_embeds` | `![[embed]]` 嵌入引用 | `!\[\[...\]\]` |
| `extract_title` | 第一个 `# 标题` 或文件名 | `^#\s+(.+)$` |
| `replace_wikilink` | 重命名时批量替换 wikilink | 同上 |

使用 `lazy_static!` 将正则编译为全局静态变量，避免重复编译。

#### [index/graph.rs](file:///Users/zmh/Documents/code/roc/roc/src-tauri/src/index/graph.rs) — 链接索引引擎
`LinkIndex` 用 4 个 `DashMap`（并发安全的 HashMap）维护笔记关系：

```
notes:       path → NoteMeta          （所有笔记元数据）
forward:     path → Vec<LinkRef>       （正向链接：这篇笔记链接到谁）
backrefs:    path → Vec<String>        （反向链接：谁链接到这篇笔记）
name_index:  stem → Vec<path>          （文件名 → 路径，用于 wikilink 解析）
```

核心方法：
- `rebuild_from_vault()`：遍历 vault 下所有 `.md` 文件，重建整个索引
- `upsert_note()`：解析笔记内容，提取链接/标签，更新所有 4 个映射
- `on_rename()`：重命名时**自动重写所有反向引用中的 wikilink**，保持链接不断裂
- `export_graph()`：导出 `{ nodes, links }` 结构供前端图谱可视化

#### [index/search.rs](file:///Users/zmh/Documents/code/roc/roc/src-tauri/src/index/search.rs) — 全文搜索引擎
基于 **Tantivy**（Rust 的 Lucene 等价物）实现：

- **Schema 字段**：`path`、`title`、`body`、`tags`、`mtime`
- **三种搜索模式**：`Fulltext`（全文）、`Tag`（按标签精确匹配）、`Link`（按 `[[link]]` 搜索）
- **索引管理**：每个 vault 有独立的索引目录（按 vault_id 区分），支持增删改查和重建
- `extract_snippet()`：从匹配位置前后各取 50 字符生成摘要，带 `…` 省略号

#### [watcher.rs](file:///Users/zmh/Documents/code/roc/roc/src-tauri/src/watcher.rs) — 文件监听器
基于 `notify` + `notify_debouncer_full` 实现：
- **防抖**：300ms 去重频繁的文件系统事件
- 只监听 `.md` 文件变化
- 将绝对路径转为相对路径后，通过 Tauri 事件 `roc://file-changed` 通知前端
- 支持三种事件：`create`、`modify`、`delete`

#### [error.rs](file:///Users/zmh/Documents/code/roc/roc/src-tauri/src/error.rs) — 统一错误处理
`AppError` 枚举定义了 11 种错误类型，通过 `#[serde(tag = "type", content = "message")]` 序列化为前端可读的 JSON。为 `std::io::Error`、`tantivy::TantivyError`、`serde_json::Error` 等实现了 `From` trait，支持 `?` 运算符自动转换。

### 数据流总结

```
前端 invoke('open_vault', {path})
  → commands::open_vault
    → VaultRegistry 注册/查找
    → FS 授权 + FileWatcher 启动
    → LinkIndex.rebuild (遍历 .md，提取链接/标签)
    → SearchIndex.build (Tantivy 索引)
    → emit('roc://vault-opened')
  ← 前端收到事件，渲染文件树

文件变化时:
  FileWatcher (notify 防抖)
    → emit('roc://file-changed', {kind, path})
    → 前端刷新对应笔记/索引
```
